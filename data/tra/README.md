此資料夾由外部整理工具（不是手機）產出。

- `latest.tsv`：只在 7 天以上連續真實臺鐵官方資料全部驗證成功後建立，內容包含日期範圍、ZIP 文件名、大小、SHA-256、車次／停站筆數。
